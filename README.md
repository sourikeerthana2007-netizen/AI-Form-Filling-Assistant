# AI-Form-Filling-Assistant
An AI-powered application that automatically fills long forms using OCR and document understanding while translating forms into the user's preferred language.
Overview

This project aims to simplify filling lengthy forms using Artificial Intelligence. Users only need to provide their personal information once, after which the application automatically fills forms by scanning documents.

Features
Automatic form filling
OCR document scanning
Multi-language translation
AI-assisted field detection
User profile management
